# Pioneers

A playable version of PIONEERS, the farm game Sadie plays in Gabrielle Zevin's *Tomorrow, and Tomorrow, and Tomorrow*.

**Play:** https://whatsupadkins.github.io/pioneers/

Arrows walk, E or Space uses things, Space/Enter advances dialogue, Esc pauses. No install needed; it runs in the browser.

This repo holds only the built game files. Phaser 3.90.0 is in `vendor/` under its own license.
